# ADR 0018: Ctrl+C 2回によるエージェント終了は krk ごと終了する

## ステータス

採用（2026-11-04）。ADR 0017 の自動再起動に例外を加える（0017 本体は変更しない）。

## コンテキスト

ADR 0017 でエージェント終了時に新セッションへ自動で置き換えるようにしたが、Claude Code を Ctrl+C 2回で抜けるのは「krk ごと終わりたい」操作であり、新セッションが立ち上がるのは意図に反した。

## 決定

- 直通状態で Ctrl+C を押したとき、ペインIDと時刻を直近2件まで記録する。キーは奪わず、従来どおりPTYへ転送する（ADR 0007 の「直通状態でアプリがキーを奪わない」を守る）
- メインタブのエージェントが終了したとき、同じペインへの Ctrl+C が2回続き、押下間隔と2回目から終了検知までがともに2秒以内なら、krk ごと終了する
- それ以外の終了（`/exit`、Ctrl+C 1回、Ctrl+D 等）は ADR 0017 どおり新セッションに置き換える

## 結果

- Claude が実際に終了したときだけ krk が終了する。作業中の Ctrl+C 連打で Claude が中断されただけなら終了しない
- Ctrl+C 2回で Claude を終了すると必ず krk も終了する。タブだけ抜けたい場合は `/exit` を使う
- 判定の窓は `CTRL_C_QUIT_WINDOW`（app.rs）で調整する
