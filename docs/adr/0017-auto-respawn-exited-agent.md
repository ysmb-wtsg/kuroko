# ADR 0017: 終了したエージェントタブを自動で新セッションに置き換える

## ステータス

採用（2026-11-04）。ADR 0016 で対象外としていた「Claude が自ら終了したタブの扱い」を補う（0016 本体は変更しない）。

## コンテキスト

タブ内で Claude Code を Ctrl+C 2回や `/exit` で終了すると、PTY は終了するがペインは終了済みのまま残り、キーを受け取る相手がいなくなる。
ユーザーからは krk が動かなくなったように見え、新規タブを開いて古いタブを閉じる手間が必要だった。

## 決定

- メインタブのエージェントの PTY 終了を検知したら、同じタブ位置で新規セッションに自動で置き換える
  - アクティブ状態は維持し、終了したタブにフォーカスがあれば新ペインへ移す
  - カスタムタブ名はクリアされる
- 起動から3秒未満で終了した場合は起動失敗（`claude` 未インストール等）とみなし、置き換えずに終了済みペインを残す。再起動ループを避けるため
- 対象はメインタブのエージェントペインのみ。ボトムターミナルタブ、エディタダイアログは従来どおり

## 結果

- タスク終了後にタブを開き直す操作が不要になる。意図的に終了した直後でも新しい Claude が立ち上がる
- 前の会話の画面は残らない（再開は `claude --resume` やセッション一覧から行う）
- 閾値は `AGENT_RESPAWN_MIN_UPTIME`（app.rs）で調整する
