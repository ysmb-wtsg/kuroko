# ADR 0019: セッションのピン留めと過去セッション検索

## ステータス

採用（2026-11-05）。ADR 0012 のセッション一覧サイドバーを拡張する（0012 本体は変更しない）。

## コンテキスト

サイドバーの HISTORY は更新順のため、繰り返し戻るセッションが他に埋もれる。
また過去セッションはタイトルしか手掛かりがなく、会話中の語から探せなかった。

## 決定

- **ピン留め**: サイドバーで `p`（トグル）。表示順は `TABS` → `+ New session` → `PINNED` → `HISTORY`
  - ピン留め対象はサイドバー上のセッション（横タブバーではない）
  - タブで開いているピン留めセッションは、既存方針どおり TABS 側のみに出し（`★` 付き）、PINNED / HISTORY には重複表示しない
- **保存先は `session.json` と分け、`~/.config/krk/pinned_sessions.json` に置く**。プロジェクト（エンコード済みcwd）ごとにセッションIDを持つ。
  `session.json` は終了時にまとめて保存する設計で、クラッシュでピンが失われるため、ピン専用ファイルをトグルのたびに即保存する
- **検索**: サイドバーで `/`。TABS は絞り込まず、PINNED / HISTORY をタイトルまたは会話内容の部分一致（大文字小文字無視）で絞る
  - 会話内容の対象はユーザー発言とアシスタントの `text` のみ。ツール入出力・thinking・メタ・タグ付き本文は除外する（ファイルパス等の誤ヒットが多いため）
  - jsonl は数MBになり得るので別スレッドで走査し、入力停止後 200ms のデバウンスを置く。生の行にクエリが含まれる行だけ JSON 解析する
  - 内容でヒットした行は、タイトルの下に一致箇所の抜粋を薄色で出す
- **検索の入力状態はペイン内部に持つ**（filer の複数選択と同様）。グローバルな状態は追加しない（ADR 0007）。
  入力中は `j` `p` 等を含む全文字がクエリになる。Enter で入力終了（絞り込み維持）、Esc でクエリ解除

## 結果

- よく使うセッションを常時上部に固定でき、語からも探せる
- 内容検索は結果が届くまでタイトル一致のみで絞る。入力中は内容のみ一致する行が一時的に消える
- 検索対象は履歴一覧の読み込み済みセッション（タイトルを抽出できないセッションは検索にも出ない）
- ピン留め済みでも jsonl が無いセッションは表示しない（ピン情報は残る）
