# ADR 0014: セッション一覧サイドバーはタブを開いたら自動で閉じる

## ステータス

採用（2026-11-04）

## コンテキスト

ADR 0012 のセッション一覧サイドバーは、Enter でタブ切り替え・セッション再開をしても表示されたまま残り、
メイン領域が狭いままになる。サイドバーは「選んで開く」ための一時的な UI として使われることが多い。
また、新規セッションの起動は `n` キーでしかできず、一覧上からは発見しづらかった。

## 決定

1. サイドバーからタブを開く操作（既存タブへの切り替え・過去セッションの再開・新規セッション）をしたら、
   続けて `Action::ToggleSessions` を発行してサイドバーを閉じる。
   サイドバーのペインがキーを受け取るのは表示中・フォーカス中のみなので、トグルで確実に閉じられる
2. TABS セクションの末尾に「+ New session」行を追加し、Enter で新規セッション（`Action::NewTab`）を起動する。
   `n` キーも同じ動作（新規セッション起動後に閉じる）とする

## 結果

- タブを開くとメイン領域が全幅に戻る。サイドバーを開いたまま複数タブを見比べる使い方はできなくなる
- グローバルモードの数字キー・`]` / `[` などサイドバー外からのタブ操作ではサイドバーは閉じない
