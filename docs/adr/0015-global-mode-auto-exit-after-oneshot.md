# ADR 0015: 単発操作後にグローバルモードを自動終了する

## ステータス

採用（2026-11-04）。ADR 0007 決定3の「持続型」を部分的に修正する（0007本体は変更しない）。

## コンテキスト

ADR 0007 のグローバルモードは持続型で、フォーカス移動のような単発操作の後も `Esc` を押さないと直通に戻らなかった。
「`Ctrl+g` → 移動 → `Esc`」の3打が毎回必要で、持続型にした理由（連打操作への対応）はリサイズ等の一部にしか当てはまらない。

## 決定

- 単発操作は実行後に直通へ自動で戻る
  - フォーカス移動 `h/j/k/l/Tab/S-Tab`、パネルトグル `f/t/g/s`、タブ `n/x/w/r/1-9`、パレット `:`、コピーモード `Enter`
- 連打系は持続を維持: リサイズ `H/J/K/L`、タブ順送り `]`/`[`
- 無効キー（割り当てなし、またはタブ操作が効かないペインでのタブキー）は持続のまま
- Lua `global` コンテキストのキーマップは対象外（挙動変更なし）

## 結果

- 移動後すぐ入力でき、`Esc` が不要になる
- 「モードが持続するか」はキーごとに異なる。README とヘルプで区別を明記する
- トグルキー・`Esc` による明示的な終了は従来どおり
