# ADR 0016: 最後のメインタブを閉じたら新セッションに置き換える

## ステータス

採用（2026-11-04）。

## コンテキスト

メインタブが1つだけのとき、タブを閉じる操作（グローバルモード `x`/`w`）は何も起きなかった。
タスク完了後は「新規タブを開く → 古いタブを閉じる」の2操作が必要で、操作性が悪かった。
`main_tabs` は常に1つ以上のタブを持つ不変条件があり、空にはできない。

## 決定

- 最後のメインタブを閉じる操作は、そのタブを破棄して同じ位置に新規セッションのタブを開く
  - カスタムタブ名はクリアされる
  - 旧ペインは `panes` から削除され、PTYプロセスは Drop で終了する（複数タブ時の閉じる処理と同じ）
- krk 自体の終了にはしない（終了は既存の終了操作に任せる）
- 複数タブ時の挙動、ボトムターミナルタブの挙動（最後を閉じるとパネルが閉じる）は変更しない

## 結果

- タスクごとにセッションを使い捨てる運用が、1操作（`Ctrl+g` → `x`）で済む
- Claude が自ら終了したタブの扱いは本ADRの対象外（未対応のまま）
